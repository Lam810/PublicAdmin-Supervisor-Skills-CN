# 盲评稿件集

本目录除本说明外全部被 `.gitignore` 忽略：稿件原文、修改稿与评分都不进入公开仓库。

## 收集

- 30–50 段公共管理稿件片段（引言、文献回顾、分析框架、案例分析或结论），每段 800–2500 字；
- 来源：博士论文章节、投稿稿、课程论文；**必须取得作者书面同意**，说明用途是评测 AI 修改工具、原文不公开；
- 尽量覆盖不同论文类型（机制解释、概念构造、政策过程实证、改革设计、理论适用、规范、综述）与不同成熟度。

## 匿名化

- 删除作者、单位、基金号、致谢；
- 地名、机构名、人名改为代号（如「A 市」「B 局」「受访者 C」），同一稿件内保持一致；
- 删除可以反查到作者的独特细节（具体年份组合、罕见项目名称、访谈编号规则）；
- 匿名化后请原作者确认不影响原意。

## 生成修改稿

对每段稿件，用**同一模型、同一温度、同一句修改指令**（例如「请修改这段公共管理论文，使其更适合投稿」）分别生成：

- `baseline`：模型直接修改，不加任何 Skill 或额外提示；
- `generic`：加一段通用学术写作提示词（不含本仓库内容）；
- `skill`：装载本仓库 Skill 后修改（记录用到了哪些 Skill 与仓库 commit）。

不要对某个系统的输出做人工挑选或多次重抽；每个系统每段只生成一次，失败才重跑并记录原因。

## 文件格式

`items.jsonl`，每行一个 JSON：

```json
{"item_id": "D07-intro", "draft": "匿名化后的原稿片段", "outputs": {"baseline": "…", "generic": "…", "skill": "…"}, "meta": {"paper_type": "mechanism", "section": "引言"}}
```

然后按 `eval/README.md` 打包、分发、评分。
