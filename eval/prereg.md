# 评测预注册（v0.2，2026-09-27 登记）

本文件在看到任何留出集结果之前写定。之后若修改，必须在文末「变更记录」中写明日期、改了什么、为什么，并且**已经跑过的结果照常报告**，不得因结果不理想而改判据后重跑。

## 0. 要回答的两个问题

1. **规则是否抓住了顶尖论文的研究结构？**（Task A，结构预测）
2. **规则是否能帮普通作者把稿件改好，而不引入虚构与过度理论化？**（Task B，盲评）

Task A 通过只说明规则能帮助模型恢复论文结构，不说明 Skill 对写作有用；项目是否有用由 Task B 决定。

## 1. 冻结条件（跑留出集之前必须满足）

- `corpus/papers.csv` 的 `split` 已分配且不再改动；形成种子规则的论文（`seed_source=1`）全部在训练集。
- 编码本版本、标注提示词（`distill/prompts/`）与规则登记表在跑留出集前打 git 标签（如 `eval-freeze-A1`），报告中写明标签。
- 标注一致性达标：同一批 ≥10 篇训练论文由两名独立标注者（至少一名为人）标注，各族 Cohen's κ ≥ 0.60（`pa_distill.py agree`）。不达标先修订编码本、重标校准集，**不得用留出论文校准**。
- 留出论文只用于评测：不得用来修改规则、编码本或提示词。

## 2. Task A：留出集结构预测

**输入**：留出论文的题名、摘要前半、研究材料说明。**预测**：PZ/GAP/CON/MECH/CTR 五族研究动作编码。**金标准**：该论文经逐字核验的标注。

**系统**：`majority`（按训练集频率猜最常见编码）、`random`、`baseline`（只给编码本）、`rules`（编码本 + 规则，不含姓名）、`rules_named`（同上 + 来源传统姓名）。

**主要指标**：每篇论文五族集合 F1 的平均；配对差的自助法 95% 区间（5000 次，seed 0）。

**成功判据（同时满足）**：

- A1：`rules − baseline` 平均差 > 0，且 95% 区间下界 > 0；
- A2：`rules − majority` 平均差 > 0，且 95% 区间下界 > 0。

**失败的解读**：A1 或 A2 不成立 → 不得宣称「蒸馏出的规则能恢复学者的研究结构」；规则只能作为启发式清单描述。只赢 `baseline` 不赢 `majority`，说明规则只起到「提示常见编码」的作用。

**Task C（去名检验）**：`rules_named − rules` 若平均差 > 0.03 且区间下界 > 0，说明模型在调用对学者本人的记忆，规则本身不完整；这时应补写规则，而不是在 Skill 里加入姓名。

**样本量**：留出论文 ≥ 20 篇（当前 24 篇，另有何艳玲待并入）。n 较小时区间会很宽，照实报告。

## 3. Task B：真实稿件盲评

**材料**：30–50 段匿名公共管理稿件（博士论文、投稿稿、课程论文），已获作者授权，去除可识别信息（见 `blind_revision_set/README.md`）。

**系统**：`baseline`（同一模型、无任何 Skill 的直接修改）、`generic`（通用学术写作提示词）、`skill`（本仓库 Skill）。三者用同一模型、同一温度、同一修改指令。

**评分**：≥ 3 名公共管理博士生或教师，互不讨论，独立按 `rubric.md` 的 D1–D8 各 1–5 分评分，并填写发现的捏造条数。评分人看不到系统名称，条目与系统顺序随机。

**成功判据（同时满足）**：

- B1：D1–D6 中至少 4 项 `skill − baseline` 平均差 > 0 且 95% 区间下界 > 0；
- B2（非劣）：D7 未过度理论化、D8 事实可靠，`skill − baseline` 的 95% 区间下界 > −0.5；
- B3（非劣）：含捏造的修改稿比例，`skill − baseline` 的 95% 区间上界 < 0.05。

**评分者一致性**：某维度 Krippendorff's α（interval）< 0.667 时，该维度只作探索性报告，不计入 B1。

**失败的解读**：B1 不成立 → Skill 相对原生模型没有可测的改稿收益；B2 或 B3 不成立 → Skill 带来可测的危害，**不得推荐使用**，先修复再测。统计显著不等于实质有用：同时报告平均差的大小。

## 4. 规则层面的主张

- 只有全套规则一起起作用时，才说「规则集合有用」；不得据此把每条规则单独标为 `validated`。
- 单条规则升为 `validated` 需要针对性证据：去掉该规则的消融让 Task A 或 Task B 的指标可测地下降，或专门的留出检验。
- 机器统计只给出建议（`rules/support.json`）；状态变更由人完成，并在提交说明中引用对应报告。

## 5. 无论结果如何都会报告的内容

每个任务的全部系统得分、全部对比的平均差与区间、样本量、一致性指标、被排除的论文或条目及原因、冻结标签。
