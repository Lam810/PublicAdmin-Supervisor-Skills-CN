# Evidence Rules

## 1. 证据等级

- **E1 原文级**：用户给出的全文、可靠数据库全文、正式期刊页面中的完整段落。
- **E2 摘要级**：正式期刊/学校主页的摘要与作者自述，可支持研究问题、方法、主要结论的大方向。
- **E3 元数据级**：题名、作者、期刊、年份，只能证明“存在这篇论文”。
- **E4 模型记忆**：不能作为具体事实或学者观点的证据。

## 2. 学者归因规则

只有 E1/E2 才可写“某文提出/发现/认为……”。  
不得由单篇论文推出“某学者一贯认为……”。要形成“认知原型”，至少需要多篇作品出现相同研究动作。

## 3. 不允许的做法

- 编造页码、引文、案例细节、样本量、回归结果；
- 把政策表述直接当作因果机制；
- 把“发生在中国”写成理论贡献；
- 用大词替代变量关系；
- 把作者的规范倡议写成实证发现；
- 让引用承担它没有证明的论断。

## 4. 写作时的 claim gate

每个关键句写出前先回答：

1. 这是事实、解释、推论还是规范判断？
2. 它由什么材料支持？
3. 证据最多能支持到多强？
4. 如果删掉这个句子，论证是否仍成立？
5. 如果它是核心句但没有证据：停止写作，先补证据或降低表述强度。
