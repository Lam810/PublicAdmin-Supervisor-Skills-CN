# 中文公共行政论文的核心逻辑

## 一篇文章不是“政策热点 + 一个理论 + 一组数据”

最低限度应该形成：

```text
经验现象
→ 反常 / 张力 / 未解释变化
→ 研究问题
→ 与既有解释对话
→ 概念或机制
→ 可观察推论
→ 证据设计
→ 发现
→ 对既有理论改变了什么
→ 边界条件
```

## 三种最常见的假创新

### 1. 情境替换
“国外研究了 X，我研究中国 X。”
- 不足：地点变化不是理论变化。
- 修复：指出中国制度条件改变了哪条机制、哪项假设或变量关系。

### 2. 概念换名
“过去叫 A，我提出 B。”
- 不足：新词没有新解释。
- 修复：给出边界、维度、相邻概念比较和可推导命题。

### 3. 方法升级
“过去案例研究，我用了机器学习 / DID / 大模型。”
- 不足：方法不是理论贡献。
- 修复：说明新方法让过去不可观测的机制、异质性或动态过程首次可检验。

## 中文公共管理 Intro 推荐结构

1. **现象与 puzzle**：只给足够背景，尽快进入“为什么奇怪/为什么重要”。
2. **解释地图**：不是堆文献，而是把文献压成 2–4 类解释。
3. **精确缺口**：现有解释在哪个条件、层次、机制或时间尺度上失效。
4. **研究问题 + 分析抓手**：一句话问题；必要时提出概念或分析框架。
5. **材料与识别能力**：为什么这些材料能回答这个问题。
6. **核心发现 / 机制链**：不要只报方向，要说明过程。
7. **理论贡献 + 边界**：具体说改变、补充、重构了什么。

## 一个好机制至少包含

```text
制度/结构条件
→ 行动者目标或约束
→ 感知与策略选择
→ 行动者互动
→ 中间过程
→ 结果
→ 反馈/稳定化（若有）
```

“政策压力导致基层形式主义”不是完整机制，因为“压力”到“形式主义”之间仍是黑箱。
