# 从主题到研究问题

读 [论证链与示例](references/argument-chain.md)，把用户的政策主题转成有证据入口的问题。

1. 用不带价值结论的一句话描述观察到的现象，记录来源、时间、对象与层级。尚未观察到的现象标为待检验设想。
2. 还原现有解释的预期及成立条件。没有文献时写“暂定解释”，不要虚构理论出处。
3. 找反常、并存、异质性、变化、稳定性或黑箱。是否存在反常本身也要核查，不能用刻意简化的理论制造冲突。
4. 指明理论对象：概念边界、机制、关系或适用条件。规范研究则指出价值冲突、理由与反驳；不要强加经验谜题。
5. 提出一个主问题，必要时给两个替代方向。比较可回答性、证据可得性、理论增量与研究成本。
6. 为主问题列出至少两个能产生不同可观察结果的解释，并说清什么证据会削弱首选解释。

“X是否影响Y”可以是有效的效果问题，但应明确估计对象及知识增量；不要仅因句式简单就排除。
“如何改善”适合规范或设计研究，须把评价标准、约束和经验依据分开。

## 交付

现象 → 预期及依据 → 困惑 → 主研究问题 → 理论对象 → 竞争解释与区分证据 → 最小可行材料。
贡献用条件句表达：“若证据支持M，则可修正C条件下的X认识。”
若现有材料不能区分解释，提供收窄问题的方案，不把一个漂亮问句当成研究完成。
