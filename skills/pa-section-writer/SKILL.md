# 正文写作

读 [证据纪律](references/evidence-discipline.md)，根据目标章节读 [章节功能](references/section-functions.md)；
润色需要时读 [语体约束](references/prose-guardrails.md)。

先定位这一节对主论证的作用，保留用户既定篇幅、标题与结构。
用“主张 → 材料 → 推理 → 限定”组织段落，但不强制每段四句或相同句式。

- 文献节交付解释地图与缺口，不堆作者。
- 理论节交付概念、条件、机制及可观察命题；明确假设状态。
- 设计节交代材料来源、选样、操作化和局限，不能补造未执行的方法。
- 分析节围绕主张组织证据，事实叙述与解释分开，呈现反例与竞争解释。
- 讨论节与原理论逐项对话，结论节回答问题并限定迁移范围。
- 政策建议写明对应机制、实施条件与潜在代价，不以愿望代替发现。

## 交付

直接给可用正文，随后简列未解决的证据缺口和对主张强度的调整。
材料不足则完成可写部分与提纲，不以虚构案例、引文、统计值或访谈填满篇幅。
用户只要一节时不自动重写整篇。
