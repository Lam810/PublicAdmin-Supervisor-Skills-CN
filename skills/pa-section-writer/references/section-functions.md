# 正文章节功能

| 章节 | 读者必须获得 | 不应代替它的内容 |
|---|---|---|
| 文献 | 解释路径、分歧、研究位置 | 按作者列摘要 |
| 理论 | 定义、假设、关系及反驳条件 | 宏大术语串联 |
| 设计 | 为什么材料能回答问题 | 只说资料丰富 |
| 案例／结果 | 按主张组织的证据与不确定性 | 编年史或回归表复述 |
| 讨论 | 发现如何改变原有认识 | 重复结果 |
| 结论 | 对问题的回答、范围与限制 | 突然加入新事实 |
| 政策含义 | 对应机制的行动、条件与代价 | 万能“加强完善提升” |

案例分析可用阶段、机制或类型组织，但应解释分段依据。
量化结果同时报告效果大小、方向、精度和实质含义；不只报告显著与否。
“没有发现效应”不等于“证明没有效应”；探索性结果与预先设定的检验分开。
