# 公共管理论文的可变骨架

## 通用的八个功能

现实入口 → 可研究问题 → 已有解释及缺口 → 概念／理论回答 → 设计与材料 → 证据和竞争解释 → 理论回扣 → 边界与含义。
八个功能可合并、换序，不等于八节；可选环节由论文目的决定。

| 体裁 | 常用顺序 | 为什么这样安排 |
|---|---|---|
| 机制案例 | 困惑—解释竞争—机制预期—选案与材料—过程比较—理论回扣 | 先给区别预测，读者才能判断材料支持哪条路径 |
| 效果检验 | 问题—文献与假设—估计对象与识别—数据—结果与威胁—讨论 | 先界定估计对象，防止用显著结果替代理论回答 |
| 概念构造 | 现象分散—旧概念局限—属性与类型—边界案例—推论与比较 | 新名称必须赚取区分力和解释收益 |
| 理论适用 | 原理论—前提—条件变化—竞争预测—材料检验—修正范围 | 先公平还原旧理论，才谈得上修正 |
| 规范论证 | 冲突—价值前提—竞争原则—案例／思想实验—反驳—条件裁决 | 应然结论需要理由，不能从实然效果直接推出 |
| 文献综述 | 问题与范围—检索纳排—解释分类—分歧综合—研究议程 | 分类与遗漏范围可复查，议程才有根据 |
| 应用／政策设计 | 具体问题—评价标准—成因证据—备选方案—成本约束—实施与评估 | 建议须对准成因并考虑可实施性，不能借学术外壳写口号 |

## 内嵌的反问

引言：为什么值得解释，而不仅值得重视？
文献：为何已有答案不足，而不是简单缺一篇本地区文章？
理论：为什么会这样，何时不会？
设计：凭什么这些材料能区分答案？
分析：证据如何支持主张，替代解释还剩什么？
讨论：由此改变哪条认识，不能改变什么？
建议：为何该行动会改变已识别的环节，有什么代价？

这些问题提供写作约束，不预设必须发现反常、必须造概念、必须得显著结果。
