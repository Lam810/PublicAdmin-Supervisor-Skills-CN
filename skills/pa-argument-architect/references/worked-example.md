# 虚构示例：减表为何没有减负

以下为教学设想，不对应真实论文、地区或访谈。

## 论文层

问题：同一减表改革后，为何甲类组织内部台账持续，乙类逐步减少？
候选回答：在问责要求未减且系统记录难以追溯责任时，组织另建台账以保存责任证据。
竞争回答：台账只是新系统学习期的临时产物。此时不能先认定问责机制成立。

## 章节层

1. 引言界定差异，解释为何“表格更少就更轻松”的预期不足；该预期须有依据。
2. 文献比较问责需求与学习成本两种解释，推出不同时间预测。
3. 理论拆出“追责需求 → 记录策略 → 重复工作”，明确哪些条件必要。
4. 设计说明怎样取得同一时期、相近任务组织的制度文本、操作记录和访谈。
5. 分析先确认台账是否持续，再检验记录用途及系统熟练度；不能跳过现象测量。
6. 讨论说明证据更符合哪种解释，保留不能排除的路径，不推广到所有数字改革。

顺序理由：没确认现象就无从解释；没区分预测就难判断材料支持谁；未交代选样就无法估计证据边界。

## 段落层：为什么保留记录用途这一段

上级问题：台账持续是否源于责任追溯？
局部主张：若责任追溯机制成立，台账应包含与追责有关的字段并在核查时被调用。
材料需求：字段与调用记录，而不只是受访者表示工作很忙。
推理桥梁：这种特定用途比一般工作负担更能区分问责与学习成本，但两者仍可能并存。
下一段：比较熟练使用系统后这些用途是否继续存在。

## 句子层：有依据的表达

“现有访谈记录显示，受访人员报告保留了内部台账。”
“这一材料与责任追溯解释一致，但也可能反映过渡期双轨运行。”
“因此，仍需结合台账字段、实际调用和系统熟练度，区分两种机制。”

第一句界定证据，第二句限制推断，第三句推出补证动作。“因此”连接的是研究设计需求，不是政策因果结论。
