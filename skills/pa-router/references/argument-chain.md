# 论证链：功能与证据

经验研究常用：现象 → 预期 → 困惑 → 问题 → 竞争解释 → 机制 → 区分证据 → 贡献与边界。
这是一组论证功能，不是固定标题或段数。描述性研究可以以测量缺口为起点；规范研究用价值冲突、理由和反驳替代机制识别。

| 环节 | 验收问题 | 常见失败 |
|---|---|---|
| 现象 | 时间、对象、层级可观察吗？ | 把政策愿景当现实 |
| 预期 | 谁的解释，在什么条件下预测什么？ | 捏造一个过弱的理论 |
| 困惑 | 观察与预期具体差在哪里？ | “很重要、研究少” |
| 问题 | 不知道答案也能成立吗？ | 问句内预设技术有效 |
| 解释 | 至少有两个可能答案吗？ | 只有首选故事 |
| 机制 | 谁在何种约束下做了什么？ | 变量之间连箭头 |
| 证据 | 什么观察会让首选解释失败？ | 只选支持材料 |
| 贡献 | 改变哪条认识，边界是什么？ | 中国案例等于理论创新 |

## 虚构教学示例

某地减少填报表格后，部分街道反而增加内部台账。这是待解释现象，不是所有改革的普遍结果。
候选解释一：问责需求未变，组织另建可追责记录；解释二：新系统学习成本导致临时双轨。
两者的区分线索是熟练使用系统后台账是否仍持续、哪些记录被用于责任追溯。
若仅有干部说“更忙了”，只能支持负担感知，不能确认哪条机制。
