# 中文学术语体约束

先修含义，再修句法与节奏。风格可以变化，事实和推论强度应保持。

| 原有风险 | 修改方向 |
|---|---|
| “数字技术赋能治理” | 指明谁获得什么信息／资源、改变什么行动 |
| “通过…从而…进而…” | 拆出未经证实的箭头，保留有材料支持的部分 |
| 多层抽象名词作主语 | 恢复行动者和动作 |
| “首次、必然、全面证明” | 检查覆盖与识别依据，必要时降为有限主张 |
| 反复“机制、逻辑、路径、范式” | 按实际含义选择术语，不为去重随意换词 |
| 背景与重要性堆叠 | 保留与问题发生直接关系的信息 |

不用统一禁词表机械替换。政策术语、理论专名、规范论证的价值词可保留，但应明确其功能。
不要为了“降AI味”加入错字、口水句、伪造个人经历或改变引用。
不把“可能”无依据删成确定陈述，也不把每句话都削弱成无法判断的模糊表达。
