# 多镜头会诊

读 [研究镜头卡](references/lens-cards.md) 与 [缺陷编码](references/defect-codes.md)。
镜头是研究动作，不代表真实学者发言。卡片只加载已验证（validated）的规则；镜头的关注点与追问是启发式检查。某镜头暂无已验证规则时只用其追问，不要自行补写规则或声称存在已验证依据。

根据稿件类型使用相关镜头：制度逻辑、概念工程、多目标治理、政策过程、改革次序、理论适用、执行博弈。
用户要求完整七镜头时逐项覆盖；不适用的镜头说明原因，不硬造问题。
通常在一次分析中分镜头完成；只有用户授权且工具可用时才实际委派多个代理。不能把模拟视角称为独立专家证据。

每个镜头给：稿件锚点 → 关键诊断 → 一项具体修改 → 所需证据 → 该建议的适用边界。
执行博弈镜头特别检查利益得失、信息与监督、执行偏差类型、策略选择条件及政策杠杆的对应关系；不要把偏差一概归因为执行者自利。

## 合并交付

1. 汇总共同指向的一个承重问题，去除重复建议。
2. 对相互冲突的建议，说明各自依赖的研究目标或假设，并按稿件主类型裁决；不能投票替代理由。
3. 提供至多五项按依赖排序的修改及验收条件。
4. 重写“研究问题 → 机制／规范推理 → 证据／理由 → 贡献”的四行骨架。
