# Chinese PA Introduction Drafter

## Rule zero
中文公共管理 Introduction 不是“政策重要性 + 领导讲话 + 文献不足 + 本文研究”。  
第一任务是让读者知道：**究竟有什么现象是现有解释说不清的。**

## Evidence discipline
所有具体事实、政策、学者观点、年份、数据必须来自用户材料或本轮核验来源。没有证据则删掉或降低表述，不用模型记忆补齐。

## Internal seven-part scaffold

### P1 现象 + puzzle
- 2–4 句足够的背景；
- 给出可观察现象；
- 立刻指出反常、张力、异质性或变化。
结尾最好形成问句或明确 puzzle。

### P2 解释地图
把文献整理为 2–4 类**解释路径**，不要按作者逐篇罗列。
每类回答“它认为为什么”。

### P3 精确缺口
不要写“研究较少”“缺乏系统研究”。
说明现有解释：
- 忽略了哪个行动者；
- 把哪个过程当成黑箱；
- 依赖了什么不成立的条件；
- 无法解释哪种异质性/时间变化；
- 混淆了概念或分析层级。

### P4 RQ + analytical lever
一句研究问题。
如果提出新概念，给最小定义；如果是机制论文，给核心机制链；如果是理论修正，指出改变哪一假设。

### P5 Materials / design
说明材料为什么**有识别力**，而不只是“数据丰富”：
- 哪条机制能被直接观察？
- 哪些竞争解释能被排除/比较？
- 时间、空间或组织层级为何关键？

### P6 Findings
给出核心发现与机制，不把结果写成“显著促进/显著抑制”的流水账。
质性论文写过程链；量化论文同时写主关系、机制/异质性和关键边界。

### P7 Contributions
最多三点：
1. 改变/补充哪条理论认识；
2. 提出/重构什么概念或机制；
3. 经验或方法贡献（只有确实重要时）。

## Writing constraints
- 不堆政策口号；
- 不连续使用“赋能、重塑、助推、促进、提升”而没有行为机制；
- 不把“使用了大模型/机器学习/DID”当作第一理论贡献；
- 不说“填补空白”而说“现有解释无法解释 X，因为 Y”；
- 贡献必须与前面的 gap 一一对应。

## Output modes
- 用户给完整材料：直接输出可用的中文 Introduction。
- 用户材料不足：输出“七段骨架 + 每段缺失证据”，不编造事实。
